# 🎓 Student Performance Predictor

## 📌 Problem Statement
Predict student performance based on study habits, attendance, and participation.

## 📊 Dataset:

🔗 Dataset Link:https://www.kaggle.com/datasets/nabeelqureshitiii/student-performance-dataset

- Features:
  - Weekly Self Study Hours
  - Attendance Percentage
  - Class Participation
- Target:
  - Total Score

## ⚙️ Approach
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Model Building (Linear Regression + Random Forest)
4. Model Evaluation
5. Deployment using Streamlit

## 🤖 Model Used
- Linear Regression
- Random Forest (Final Model)

## 📈 Results
- R2 Score: ~0.71

## 🚀 Deployment
- Streamlit app for real-time prediction

## 🎯 Outcome
Users can input student details and get predicted performance instantly.
